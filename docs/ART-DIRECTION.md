# 美術方向

## 可選風格與本版選擇
| 風格 | 特性 | 適用 |
|---|---|---|
| 夜間電台 × 音樂雜誌（採用） | 靛藍舞台、淡紫唱片、細緻排版、少量螢光綠 | 音樂與短回合學習 |
| 昭和街機 | 點陣字、像素圖示、高密度資訊 | 競速挑戰 |
| 和紙手帳 | 紙張紋理、手寫註記、安靜留白 | 長時間閱讀 |
| 日本車站導視 | 模組格線、路線色、清楚層級 | 分級課程 |

## 色票
背景 #10131e；面板 #191e2c；深層 #232a3c；月光白 #f1f0f7；次要文字 #a9afc2；軌道紫 #c1acf3；芽綠 #d4ed9a；錯誤 #ffadaf。顏色皆以 CSS Variable 管理。正文對比以可讀性為先。

## 字體
主標題使用 Yu Gothic／Hiragino Kaku Gothic ProN 無襯線；內文使用系統繁體中文字型；資料標籤使用 Consolas 等寬字型。不依賴外部字型下載。日文用 lang=ja 標示。

## 版型與元件
桌機固定左導覽 224px，內容最大寬度 1400px；主視覺採左文右 3D 唱片、下方四張遊戲卡。曲目館使用有編號的唱片清單。卡片 16px 圓角、1px 低對比邊界；主要按鈕淡紫底深色字；觸控目標至少 44px。學習題目置於原生 dialog，最大 680px，明確進度、下一題與結束操作。

## 動畫原則
唱片輕緩旋轉，指標小幅改變視角；不自動播放聲音。prefers-reduced-motion 時停止環境動畫，背景頁面隱藏時停止算圖。答題回饋靠文字與符號，不只靠顏色。

## 禁止事項
不使用未授權藝人照片、封面、歌詞或音源；不堆疊光暈與玻璃效果；不偽造排行榜、人數與學習成就；不將工具名稱放入學習流程；不將錯答做成羞辱或懲罰。3D 只強化唱片概念，不妨礙閱讀或操作。
