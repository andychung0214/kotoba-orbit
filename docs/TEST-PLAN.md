## 手動腳本
1. 首頁進入假名；答錯一題，確認正解與解說；完成、重玩、離開。
2. 詞彙先選右側，應提示先選左側；錯配、重新配對、完成。
3. 句子未排完先確認，應提示；移回已選詞塊、重排、答題。
4. 讀本核對原作來源，確認外連新分頁且不截取／播放未授權內容。
5. 三組螢幕尺寸檢視主標題、唱片舞台、遊戲卡與曲目清單。
6. 開啟減少動態，場景停止自動旋轉；禁用 WebGL，保留替代圖。
