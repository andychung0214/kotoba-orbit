# 題庫與隨機題型擴充計畫

日期：2026-10-21。沿用既有原生 JavaScript 與靜態部署；完成全部驗證後才更新 GitHub。

## 需求與設計
- 四種遊戲均支援基礎／中階／進階，不再讓假名與歌曲忽略難度。
- 假名：清音、濁音／半濁音、拗音；讀音辨識、讀音選字、平片互換。
- 詞彙：每級至少 24 個，漢字配中文、漢字配讀音、讀音配中文。
- 句子：每級 24 句；重組、句意選擇、中文提示填空。保留原有常見替代語序。
- 歌曲：16 首每級 18 題（6 個主題／閱讀詞彙各兩種問法、2 句原創例句各兩種問法、2 題原作／作者背景），每首 54 題，共 864 題；混合四種類型出題，保留原作與來源導讀。
- 混合題型平均輪替；選題先避開上一局內容，候選不足才補回；每局同一素材不重複，選項隨機且唯一正解。防重複歷史僅保留當次開啟頁面，不寫入學習進度。
- 既有 XP 與回合紀錄相容。每局綁定開始時的難度、題型與字形，重玩沿用設定。

## 實作步驟
1. tests/expansion.test.js：資料最低量、全遊戲／難度／題型矩陣、無重複、混合涵蓋、隨機種子、上一局避重與資料不變性測試。
2. src/expanded-content.js、src/song-lessons.js：原創內容。src/question-bank.js：把教材轉為明確題目與選項。core.js 增加 sampleRound(pool, count, previous, random)。
3. app.js 接入題型與難度選擇、不同問答版型、詞彙配對標籤；更新首頁、小抄、讀本題數與紀錄。
4. tests/browser.js 改為依題目 id 查核題庫答案，完成每種遊戲／難度／題型，以及全部 16 曲目三難度的回合，檢查重玩與手機。
5. 獨立審查、修正、更新 README／TEST-PLAN／VERIFICATION，驗證後提交並推送原 Pages 分支。

## 驗收與風險
所有題庫答案唯一；填空附中文提示以排除語境歧義；同音假名逆向題須附行別；歌曲所有例句清楚標示原創，不能聲稱取自歌詞。隨機測試用可注入亂數驗證，不靠機率判斷是否通過。無後端與新外部依賴。部署前展示 remote／branch／commit，部署後核對工作流程及正式頁面。
